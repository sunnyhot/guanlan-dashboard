# 投资研究阅读指南

> 本指南对应旧版「研究阅读指南」弹窗（审计项 A5，已确认放弃 UI 形态，
> 改为文档承载）。首次阅读研判结果前建议先看一遍。

## 怎么读投资智能的研判结果

「投资智能」板块的产出分四层，每层的可信度来源不同：

| 层 | 内容 | 可信度来源 |
|---|---|---|
| 盘中执行建议 | HOLD / EXECUTE + 逐持仓 Δw | 纯本地计算（对照你的战略目标），不经过模型 |
| 市场机会 | top-K 候选 + 因子摘要 + 失效条件 | 本地因子筛选（动量/趋势/波动/回撤），不经过模型 |
| 组合研究 | 论点 + 信号 + 决策方案 | AI 研究产出，每条信号可点开查看引用的证据与数据截至 |
| 收盘复盘 | 当日表现 + 逐持仓归因 + 市场叙述 + 明日关注 | 表现与归因为纯计算冻结；市场脉搏标注「AI 叙述」或「本地因子」来源 |

三个关键数字的读法：

1. **偏差（当前 − 目标）**：正数 = 超配，负数 = 低配。带内（±5%）不触发
   调整建议，这是刻意设计——避免微小偏差反复触发动作。
2. **Δw（调整幅度）**：唯一来源是对照战略目标的规划器（provenance 标注
   来源：目标跟随 / 修正 / 用户指令），模型与信号不参与调整幅度计算。
3. **证据数 / 信号数**：信号由证据推导（每条信号可点「依据」看明细）。
   证据数为 0 的结论不值得采信。

## 立场声明

- 本应用的所有研判都是**决策辅助**，不是投资建议；最终决策由你做出。
- AI 研究可能出错：证据可能过时（查看「数据截至」），模型可能误读。
  失效条件命中时，请把对应结论视为已过期。
- 决策事项的「触发/失效条件」是自然语言提示，需人工复核，系统不会自动
  执行任何交易。
- 中国股市惯例：红色涨、绿色跌（本应用全程遵循）。

## 术语速查

| 术语 | 含义 |
|---|---|
| 战略目标 | 你设定的五类资产（股票/债券/商品/现金/另类）目标占比，只从你的编辑动作产生 |
| Δw | 调整幅度（权重变化），正=增持、负=减持 |
| provenance | Δw 的来源标注（目标跟随 / 修正 / 用户指令）——审计追溯用 |
| 穿透（look-through） | 把基金持仓拆到底层证券后的真实暴露 |
| HHI | 赫芬达尔指数，衡量集中度（越大越集中） |
| 证据 vintage | 同一证据 ID 的不同版本；查看时永远取最新未废弃版本 |
| 决策事项 | 需要你关注的组合风险跟踪项（集中度/回撤/目标偏离/行动迁移），带生命周期与复盘 |
| 收盘复盘 | 每日 21:00 冻结的当日组合表现与市场叙述（immutableHistorical，重跑不改写历史） |
| fail-closed | 输入不完整时明确失败/禁用，不用默认值冒充结果 |
| 复盘六选一 | 判断成立 / 部分成立 / 判断不成立 / 无法定论 / 提前失效 / 数据不足 |
