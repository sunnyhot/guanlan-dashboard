# Apple HIG 对照审查报告 + 改进清单

日期：2026-07-27
项目：qieman-manager-dashboard（macOS SwiftUI）
标准：Apple Human Interface Guidelines (macOS)

---

## 一、评级总览

| HIG 领域 | 评级 | 关键发现 |
|---|---|---|
| 1. 菜单栏 | ⚠️ | 标准菜单自动补齐 ✓；但自定义菜单位置偏离标准槽位；2 项无快捷键；**0 处 .contextMenu** |
| 2. 窗口 | ⚠️ | 可缩放 ✓；**红绿灯关闭被劫持**(orderOut)；无显式 autosave 持久化；hiddenTitleBar 重度定制 |
| 3. 工具栏 | ❌ | **无原生 .toolbar**（全自绘 VStack）；无 .searchable；视图切换非原生 segmented |
| 4. 侧边栏 | ⚠️ | NavigationSplitView ✓ + vibrancy ✓；**不可折叠**；非原生 List(.sidebar)；无 badge；无拖排 |
| 5. 键盘 | ⚠️ | 菜单快捷键 ✓ + Return/Esc ✓；**无箭头键列表导航、无 Delete、无 Quick Look、无 Cmd+Z** |
| 6. 指针 | ⚠️ | Hover ✓；**0 处 .contextMenu**；无多选；无光标变化；拖放仅 1 处 |
| 7. 可访问性 | ⚠️ | VoiceOver label ✓(27处) + Reduce Motion ✓(18处)；**Reduce Transparency ❌、Bold Text ❌、Increase Contrast ❌** |
| 8. 系统集成 | ⚠️ | 菜单命令 ✓；**无 Dock 菜单、无 Spotlight、无 ShareLink、无 App Intents**；无 Settings Scene |
| 9. 视觉设计 | ⚠️ | 暗色模式 ✓ + material ✓；**691 处硬编码字号**(appFont token 建了没用)；系统强调色被 brand 覆盖 |
| 10. 通知 | ✅ | 克制、仅重要事件；缺 suppression 选项 |
| 11. 反模式 | ✅ | 无汉堡/底部 tab/FAB；sheet 合理；硬编码色极少 |

**总分：2 ✅ / 7 ⚠️ / 1 ❌（工具栏）**

## 三、本次建议执行的（P0 全部 + 部分 P1）

1. **.contextMenu** — 给侧边栏导航项、持仓行、调仓卡片、趋势跟踪项加右键菜单
2. **Reduce Transparency** — material 降级
3. **补快捷键** — 打开数据目录、检查更新
4. **ShareLink** — 报告导出
5. **侧边栏 badge** — 计数显示
6. **侧边栏可折叠** — columnVisibility 绑定 + 命令注册

P2（字体迁移/原生 toolbar/原生 List/Undo/箭头键）属大工程，建议分专项排期。
